# 悬挂绳

常驻屏幕顶端的文件中转站：把东西拖上绳挂着，要用时拖下来即可。
纯本地运行，不登录、不联网（唯一例外见下）、不上传任何数据。

## 启动

- 开发调试：`npm start`
- 日常使用：双击 `start.bat`（或 `npx electron .`）
- 打包成独立 exe：先 `npm i -D electron-builder`，再 `npm run dist`

启动后在任务栏右侧托盘有图标，右键可显示 / 设置 / 清空 / 退出。

## 测试

```bash
npm test          # 单元测试 + 全部 Electron 场景（共 112 项）
npm run test:unit # 只跑纯 Node 单元测试（数据层 / 窗口几何 / 拖出决策 / 图片格式）
npm run test:e2e  # 只跑 Electron 场景（窗口形态、手势、持久化、快捷方式等）
```

- 单元测试在 `test/unit/`，不启动 GUI，约 1 秒跑完。
- 端到端场景在 `test/e2e/scenarios.js`，会用**独立临时数据目录**启动 Electron，不会读写你真实的 `%APPDATA%\悬挂绳`，也不会和正在运行的实例抢单实例锁。
- 自动化无法覆盖"真实拖到微信/Word""托盘图标""目录选择框"，这几项见 `DEVPLAN.md` 第 3 节手工清单。
- 完整开发计划与验收对照表见 `DEVPLAN.md`，需求见 `PRD.md`。


## 使用方法

| 操作 | 方式 |
| --- | --- |
| 唤出绳索 | 鼠标移到屏幕最顶端（绳索居中，占屏幕宽 1/3；停留约 0.1 秒） |
| 悬挂内容 | 把 文件 / 文件夹 / 文字 / 图片（含网页里的图，PNG/JPEG/GIF/WebP/SVG/AVIF 均可）拖到绳上 |
| 粘贴悬挂 | 鼠标停在绳上时按 `Ctrl+V`，剪贴板内容直接挂上绳 |
| 取下挂件 | **按住 `Esc`**（按住不放，挂件出现“取下”角标）→ 点击要取下的挂件 → 松开 `Esc`。按住期间可连续取下多件 |
| 固定子文件夹 | 悬停文件夹挂件展开列表，子文件夹行右侧的 📌 点一下就能把它固定到绳上（已在绳上则不重复添加）；拖出仍然是在行上按住拖动 |
| 翻看更多挂件 | 鼠标在绳索条内任意位置（包括挂件下方的空白处）滚动滚轮 = 挂件横向滚动 |
| 拖出插入 / 排序 | 同一个手势：按住挂件约 0.15 秒"抬起"后，横向移动 = 排序换位；**向下拖出窗口** = 转成对外拖出，拖到聊天框 / Word 里松手 |
| 图片预览 | 图片挂件本身就是大预览图，挂上即可看清内容 |
| 文件夹翻看 | 鼠标停在文件夹挂件上，弹出竖排列表（一屏 3 行），滚轮切换选择，选中行高亮 |
| 拖出文件夹里的文件 | 在浏览列表里按住某一行拖出去即可 |
| 复制即悬挂 | 快捷键 `Ctrl+Alt+H` 开关；开启后复制的内容自动挂上绳（支持文件复制） |
| 文字/图片快速粘贴 | 双击挂件 = 复制到剪贴板 |
| 恢复上次悬挂 | 重启程序后会询问是否恢复关机前的挂件 |
| 设置 | 点绳索右上角「设置」（或托盘菜单「设置」），会打开一个独立的普通窗口，带标题栏关闭按钮，鼠标移开顶部也不会消失 |

要点：

- **文件/文件夹挂件只存路径引用**，不复制本体，几乎不占空间；原文件被移动/删除后挂件会标灰为"源已丢失"。
- **.lnk 快捷方式**挂上时会自动解析并映射到它指向的本体，拖出去的是真文件，不再是快捷方式；启动时会对旧挂件重新解析一次（自愈）。若快捷方式指向的对象已被移动/删除（悬空），挂件保持原样，拖出时降级发送 .lnk 本身并给出提示。
- **文字**随悬挂记录存入本地 `state.json`（单条上限 50KB）。
- **图片**会存一份压缩副本到缓存目录（默认 `%LOCALAPPDATA%\HangingRope\cache`，可在设置中更换并自动迁移），总量默认上限 200MB，超限会提示。
- **悬挂记忆**保存在 `%APPDATA%\悬挂绳\state.json`，随改随存，关机不丢。
- 若程序异常退出，可查看 `%APPDATA%\悬挂绳\crash.log` 排查原因。

## 关于联网

工具本身不联网。只有一种情况会产生网络请求：**从浏览器里拖一张网页图片到绳上**时，程序需要把这张图片下载到本地缓存（这是"挂住网页图片"绕不开的一步）。抓取失败时会有提示，可改用"复制图片后拖入"。

## 已知限制（第一版）

- 拖出**文件/文件夹**到微信、QQ、Office 最稳定；拖出**纯文字**到个别聊天窗口可能被对方拒收（此时双击挂件复制，再 Ctrl+V 即可）。
- 网页上拖拽相对路径的图片无法直接抓取。
- 暂不支持开机自启、挂件搜索、多显示器精细适配。
