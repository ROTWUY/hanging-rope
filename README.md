# 悬挂绳

常驻屏幕顶端的文件中转站：把东西拖上绳挂着，要用时拖下来即可。
纯本地运行，不登录、不联网（唯一例外见下）、不上传任何数据。

## 启动

- 开发调试：`npm start`
- 日常使用（源码态）：双击 `start.bat`（或 `npx electron .`）
- 日常使用（发布态）：双击 `dist\悬挂绳-免安装-1.18.0.exe`，或用安装版装到本机；两者都不需要 Node.js

启动后在任务栏右侧托盘有图标，右键可显示 / 设置 / 清空 / 退出。

## 测试

```bash
npm test          # 单元测试 + 全部 Electron 场景（共 283 项）
npm run test:unit # 只跑纯 Node 单元测试（数据层 / 窗口几何 / 拖出决策 / 图片格式 / 路径归一化 / 去重）
npm run test:e2e  # 只跑 Electron 场景（窗口形态、手势、持久化、快捷方式等）
```

- 单元测试在 `test/unit/`，不启动 GUI，约 1 秒跑完。
- 端到端场景在 `test/e2e/scenarios.js`，会用**独立临时数据目录**启动 Electron，不会读写你真实的 `%APPDATA%\悬挂绳`，也不会和正在运行的实例抢单实例锁。
- 自动化无法覆盖"真实拖到微信/Word""托盘图标""目录选择框"，这几项见 `DEVPLAN.md` 第 3 节手工清单。
- 完整开发计划与验收对照表见 `DEVPLAN.md`，需求见 `PRD.md`。

## 打包成 EXE（Windows x64）

```bash
npm install            # 依赖已含 electron-builder，首次或换机器时执行
npm run dist           # 同时产出「安装版」+「免安装单文件」
npm run dist:portable  # 只产免安装单文件
npm run pack           # 只产未压缩绿色目录，便于排查打包问题
```

产物放在 `dist/`：

| 文件 | 用途 |
| --- | --- |
| `悬挂绳-免安装-<版本>.exe` | **推荐**：单文件、双击即用，不写注册表、不需要管理员权限，拷到别的电脑也能跑 |
| `悬挂绳-安装版-<版本>.exe` | NSIS 安装向导，可改安装目录、建桌面 / 开始菜单快捷方式；安装到当前用户目录，不需要管理员权限 |
| `win-unpacked/` | 未压缩的绿色目录，调试用（`npm run pack` 也会产出） |

要点：

- EXE 自包含 Electron 运行时与 `app.asar`（主进程、渲染层、preload、托盘图标），目标机器**不需要 Node.js / npm**。
- 挂件数据仍写在 `%APPDATA%\悬挂绳\state.json`、图片缓存仍在 `%LOCALAPPDATA%\HangingRope\cache`，与 `start.bat` 源码态共用同一份；换用 EXE 后原有挂件照常恢复。
- 图标资源在 `app.asar` 内，主进程用 `fs.readFileSync` + `nativeImage.createFromBuffer` 读取，避免打包后托盘 / 拖拽图标丢失。
- 未做代码签名（无证书）：首次运行 Windows SmartScreen 可能提示「未知发布者」，选「更多信息 → 仍要运行」即可；软件本身仍不联网。
- `dist/` 已在 `.gitignore` 中，打包产物不入库。
- 国内网络若下载 Electron / NSIS 二进制失败，可设置 `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/` 与 `ELECTRON_BUILDER_BINARIES_MIRROR=https://npmmirror.com/mirrors/electron-builder-binaries/` 后再执行 `npm run dist`。


## 使用方法

| 操作 | 方式 |
| --- | --- |
| 唤出绳索 | 鼠标移到屏幕最顶端（绳索居中，占屏幕宽 1/3；停留约 0.1 秒） |
| 悬挂内容 | 把 文件 / 文件夹 / 文字 / 图片（含网页里的图，PNG/JPEG/GIF/WebP/SVG/AVIF 均可）拖到绳上 |
| 粘贴悬挂 | 鼠标停在绳上时按 `Ctrl+V`，剪贴板内容直接挂上绳 |
| 取下挂件 | **按住 `Esc`**（按住不放，挂件右上角出现红色「×」角标）→ 点击要取下的挂件 → 松开 `Esc`。按住期间可连续取下多件 |
| 固定 / 取消固定子文件夹 | 悬停文件夹挂件展开列表，子文件夹行右侧的 📌 **点一下固定到绳上，再点一下取消固定**（蓝色 = 已固定）；同一路径不会重复挂，拖出仍然是在行上按住拖动 |
| 翻看更多挂件 | 鼠标在绳索条内任意位置（包括挂件下方的空白处）滚动滚轮 = 挂件横向滚动 |
| 拖出插入 / 排序 | 同一个手势：按住挂件约 0.15 秒"抬起"后，横向移动 = 排序换位；**向下拖出窗口** = 转成对外拖出，拖到聊天框 / Word 里松手 |
| 图片预览 | 图片挂件本身就是大预览图，挂上即可看清内容 |
| Office 文档图标 | Word / Excel / PowerPoint 文档挂上后显示对应的彩色应用图标（卡片和文件夹面板里都一样）；其它文件仍显示扩展名文字卡，详见下方「界面风格」 |
| 文字挂件 | 卡片里**只显示一处正文**（最多 6 行，撑满卡片），下方不再重复一行截断摘要 |
| 文件夹翻看 | 鼠标停在文件夹挂件上，弹出竖排列表（一屏 3 行），滚轮切换选择，选中行高亮 |
| 拖出文件夹里的文件 | 在浏览列表里按住某一行拖出去即可 |
| 复制即悬挂 | 快捷键 `Ctrl+Alt+H` 开关；开启后复制的内容自动挂上绳（支持文件复制，绳上已有的同一内容不重复挂） |
| 重复悬挂 | 同一个文件/文件夹（含桌面图片文件）、同一张图或同一段文字，不管从哪个入口挂，绳上始终只有一张；重复项自动跳过并提示「已在绳上，未重复添加」。旧版本已经挂出的重复卡片，重启时会自动合并成一张 |
| 单击复制 | **单击**挂件或文件夹面板里的行（未按住拖动）= 复制到剪贴板：文字/图片是内容，文件/文件夹是可直接粘贴的文件对象 |
| 双击打开 | **双击**挂件或面板行 = 用系统默认程序打开（文件夹进资源管理器、图片用看图器）；文字没有文件本体，退化为复制并提示 |
| 恢复上次悬挂 | 重启程序后会询问是否恢复关机前的挂件 |
| 设置 | 点绳索右上角「设置」（或托盘菜单「设置」），会打开一个独立的普通窗口，带标题栏关闭按钮，鼠标移开顶部也不会消失 |
| 切换主题 | 设置窗口「外观」卡片里点「浅色」或「深色」，绳索与设置窗口同时换色；选择记住，重启后沿用 |
| 件数上限 | 设置窗口「悬挂绳」卡片里点数字：`200 / 300 / 350 / 400 / 450 / 500`，默认 **300 件**。满额后新挂件不再添加（一次拖一批只挂到剩余名额，其余跳过并提示）；调低上限**不会删除**已有挂件，只拦新增，调高或取下后立刻恢复 |
| 多选 | 状态栏「多选」按钮（或直接 **Ctrl+点击**挂件）进入多选：多选下**普通单击即可勾选**（Ctrl+点击也可以），选中的挂件带绿色对勾；多选状态下单击复制 / 双击打开**停用**（点击只做勾选）；按住选中件拖动 = **整组换位**；拖出窗口 = 整组按绳上顺序插入 Office / 聊天软件，文字等不可插入的对象**自动跳过**并提示；Esc 或再点按钮退出。只发路径引用，不复制文件本体 |
| 停靠位置 | 设置窗口「悬挂绳」卡片（或托盘右键菜单）选 **顶部 / 左侧 / 右侧 / 底部**，默认顶部。左右 = 竖绳贴边、长度约屏高 **1/2.5**、垂直居中，挂件朝屏幕内侧挂，状态栏变成绳子外侧的竖向图标栏（只显示图标，鼠标悬停向屏幕内侧浮出文字）；底部 = 横绳贴底边（避开任务栏）、挂件向上挂。切换立即生效并记住；鼠标贴当前停靠边唤出，手感与顶部版一致 |

要点：

- **文件/文件夹挂件只存路径引用**，不复制本体，几乎不占空间；原文件被移动/删除后挂件会标灰为"源已丢失"。
- **全入口统一去重**：文件/文件夹按路径（大小写、斜杠、末尾分隔符等价，`.lnk` 与其本体算同一个）判重，图片按内容、文字按全文判重。拖入两次、复制即悬挂、`Ctrl+V`、📌 固定都共用这一套规则；批量里重复项跳过但其它内容照常挂上。取下或清空后可以重新挂上。
- **.lnk 快捷方式**挂上时会自动解析并映射到它指向的本体，拖出去的是真文件，不再是快捷方式；启动时会对旧挂件重新解析一次（自愈）。若快捷方式指向的对象已被移动/删除（悬空），挂件保持原样，拖出时降级发送 .lnk 本身并给出提示。
- **文字**随悬挂记录存入本地 `state.json`（单条上限 50KB）；卡片里只有一处正文预览，文件/文件夹/图片的名称行不受影响。
- **图片**会存一份压缩副本到缓存目录（默认 `%LOCALAPPDATA%\HangingRope\cache`，可在设置中更换并自动迁移），总量默认上限 200MB，超限会提示。
- **悬挂记忆**保存在 `%APPDATA%\悬挂绳\state.json`，随改随存，关机不丢。
- 若程序异常退出，可查看 `%APPDATA%\悬挂绳\crash.log` 排查原因。

## 界面风格

提供**两款主题**，在「设置 → 外观」里点「浅色 / 深色」即可切换，绳索窗口与设置窗口同时生效，选择会记住，重启后按上次主题渲染（深色不会先闪一下浅色）。两套主题只换配色，卡片尺寸、圆角、手势、拖出与复制行为完全一样。

| 主题 | 底 / 卡片 | 文字 | 强调色 |
| --- | --- | --- | --- |
| 浅色（默认） | 浅灰白 `#f4f7fb` / 纯白卡片 | 近黑 `#1f2430` | `#4b86f5` |
| 深色 | 深灰蓝 `#1b1f28` / `#262c38` 卡片 | 近白 `#e9eef7` | 提亮蓝 `#5b93ff` |

设计语言是 Windows 11 Fluent 风：中性底 + 圆角卡片 + 细描边 + 淡阴影、不用渐变。**颜色有明确语义**——绿 `rgb(0,198,92)` 只表示「开关型开启态」（复制即悬挂、多选按钮、选中对勾），蓝 `#4b86f5` 表示「单选选中 / 可交互」（📌 已固定、抬起描边、设置主按钮、主题与件数档位的选中按钮），红只留给「取下 / 警告」。浅色悬浮条靠细边框与淡投影在白色壁纸上保持层次，深色悬浮条靠纯黑投影拉开层次；设置窗口、图标（蓝底白绳）沿用同一套语言。主题选择存在 `state.json` 的 `settings.theme`，只有 `light` / `dark` 两个合法值。

v1.17 起界面按 Apple 设计原则做过一轮质感打磨：字号收敛为 11 / 12.5 / 17 三档（挂件文件名升为 12px 中字重，全项目不再有 9~10px 的虚字）；文件夹面板、提示条、竖排悬停标签改为**半透明磨砂材质**（`backdrop-filter` 模糊 + 提饱和，随系统「减少透明度」设置回退实色）；间距统一到 4px 基线；文件夹面板从触发卡片那一侧「长」出来，四个停靠方向各有自己的入场方向。

## 更新日志

每个版本的改动见 [CHANGELOG.md](CHANGELOG.md)，发布包在同仓库的 [Releases](https://github.com/ROTWUY/hanging-rope/releases) 页。

**Office 文档例外**：Word（蓝 / W）、Excel（绿 / X）、PowerPoint（橙红 / P）三款彩色应用图标是 `assets/` 下的自绘 SVG，卡片缩略图和文件夹面板里的文件行都会用；两套主题共用同一份，不加滤镜。识别 `.doc/.docx/.xls/.xlsx/.ppt/.pptx` 等常见 Office 扩展名（大小写无关），WPS、`.rtf`、`.csv`、`.odt` 等仍用通用文档形状。图标只影响显示，不改卡片尺寸、文件名和数据；SVG 万一加载失败会自动退回原来的扩展名文字卡。

## 关于联网

工具本身不联网。只有一种情况会产生网络请求：**从浏览器里拖一张网页图片到绳上**时，程序需要把这张图片下载到本地缓存（这是"挂住网页图片"绕不开的一步）。抓取失败时会有提示，可改用"复制图片后拖入"。

## 已知限制（第一版）

- 拖出**文件/文件夹**到微信、QQ、Office 最稳定；拖出**纯文字**到个别聊天窗口可能被对方拒收（此时单击挂件复制，再 Ctrl+V 即可）。
- 网页上拖拽相对路径的图片无法直接抓取。
- 旧版本挂上的图片如果缓存副本已丢失，启动时无法补算内容指纹，去重只能按缓存路径判断；这种失效挂件不会被误删，手动取下即可。
- 暂不支持开机自启、挂件搜索、多显示器精细适配、抓着绳身拖拽换边（换边走设置页 / 托盘菜单）。
- 挂件件数上限只有 6 个固定档位（默认 300），不开放任意数值，也不做虚拟滚动；上限以上不保证操作流畅。挂件只存路径，与原件体积无关。
- 主题只有浅色 / 深色两套预设，不跟随系统深浅色自动切换，也不开放自定义配色。
- Office 图标只内置 Word / Excel / PowerPoint 三款，不读取系统文件关联图标；WPS 的 `.wps` / `.et` / `.dps` 等格式仍显示通用文档形状。
